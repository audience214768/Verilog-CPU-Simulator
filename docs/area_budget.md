# 面积预算与消融（ASAP7 7nm, RVT+TT, 标准单元）

> 报告素材。数据来源：`make synth`（mul）、`make synth-cpu`（全核），YoSys 0.68 + ASAP7 r1p7。
> 口径：**"核心面积" = 全部标准单元面积（含触发器）**；64KB 主存 memory 当 SRAM 宏黑盒排除，另列估算。
> 触发器成本：DFFHQNx1 = 0.2916 µm²/bit（ASAP7 最小 DFF，同步低有效复位）。

## 1. 实测面积（当前代码状态）

| 设计 | 面积 (µm²) | 说明 |
|---|---|---|
| 乘法器 mul（Booth + Wallace 树） | **555.2** | 四库合并 + `map -a`；单库基线 613.7 |
| 全核 cpu_top（默认参数，Phase B 前） | **1139.9** | 组合逻辑为主；core 存储模块为桩（FF=0），Phase B 后显著增加 |

全核 1139.9 构成：execute_slot（含 mul/adder/alu/流水寄存器）392.7 + cpu_top 其余（取指/译码/控制，112 个 DFFHQNx1 = 32.7）747.2。

乘法器分解（555.2）：Booth 编码 + 部分积生成 187；6 层 Wallace 树 140+93+58+47+23+23；64 位加法器 44。

## 2. 存储面积预算（默认参数）

| 结构 | 位宽计算 | bit | 面积 (µm²) |
|---|---|---|---|
| RS | 16 项 × (32×2 数据 + tag 等) | 2320 | 676 |
| PRF | 64 × 32 | 2048 | 597 |
| ROB | 32 × (32 数据 + tag + 控制) | 1962 | 572 |
| LSQ | 16 × (32 地址 + 32 数据 + 控制) | 1320 | 385 |
| RAT | 32 × 6 | 192 | 56 |
| RAS | 8 × 32 + 控制 | 259 | 76 |
| BHT | 32 项 × 2 | 64 | 19 |
| ready_table | 64 | 64 | 19 |
| free_list | 32 × 13 | 13 | 4 |
| **合计** | | **8242** | **≈2400** |

每 bit 按 0.29 µm²（DFFHQNx1）；部分结构（如 RS 数据位）可用无复位 DFFLQNx1（同价）或压缩编码，此处为上限估算。

## 3. 预算与达标策略

默认参数预估：存储 ≈2400 + 组合 ≈500（mul/alu/取指，按桩版实测外推）≈ **2900+ µm²，超出 1500-2000 目标**。
必需参数收敛（消融扫描范围见第 4 节）：

| 参数 | 默认 | 最小合理 | 面积影响 |
|---|---|---|---|
| ROB_SIZE | 32 | 8 | -1000 bit ≈ -290 |
| RS_SIZE | 16 | 4 | -1740 bit ≈ -507 |
| PRF_SIZE | 64 | 16 | -1536 bit ≈ -448 |
| LSQ_SIZE | 16 | 4 | -990 bit ≈ -289 |
| BHT/RAS | 32/8 | 16/4 | -130 ≈ -38 |

最小配置合计 ≈ (8242-5260) × 0.29 ≈ **870 µm² 存储**，全核 ≈ 870+500 ≈ **1370-1500 µm²**，可落在目标区间。
1.3× 验证口径：双发射 vs 单发射——存储阵列（占大头）不翻倍，面积比预计 1.3-1.5×，性能比目标接近 IPC 翻倍。

## 4. 消融实验设计（Phase B 后执行）

- 固定点：多发射数（单/双发射）、工艺角（RVT+TT）
- 扫描：ROB_SIZE / RS_SIZE / PRF_SIZE / LSQ_SIZE / BHT_SIZE / RAS_SIZE 各 2-3 档（含默认与最小配置）
- 每档记录：`make synth-cpu` 面积 + 仿真 IPC（perf 数据接 tb 后）
- 输出：面积-性能曲线，标注每档性能损失，选 1500-2000 区间内的最优配置
- 1.3× 验证：单发射 vs 双发射面积比与性能比对照
