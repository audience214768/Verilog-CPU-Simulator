# 面积预算与消融（ASAP7 7nm, RVT+TT, 标准单元）

> 报告素材。数据来源：`make synth`（mul）、`make synth-cpu`（全核），YoSys 0.68 + ASAP7 r1p7。
> 口径：**"核心面积" = 全部标准单元面积（含触发器）**；64KB 主存 memory 当 SRAM 宏黑盒排除，另列估算。
> 触发器成本：DFFHQNx1 = 0.2916 µm²/bit（ASAP7 最小 DFF，同步低有效复位）。

## 2. 存储面积预算（默认参数）

| 结构 | 位宽计算 | bit | 面积 (µm²) |
|---|---|---|---|
| RS | 16 项 × (32×2 数据 + tag 等) | 2320 | 676 |
| PRF | 64 × 32 | 2048 | 597 |
| ROB | 32 × (32 数据 + tag + 控制) | 1962 | 572 |
| LSQ | 16 × (32 地址 + 32 数据 + 控制) | 1320 | 385 |
| RAT | 32 × 6 | 192 | 56 |
| RAS | 8 × 32 + 控制 | 259 | 76 |
| BHT | 32 项 × 2 | 64 | 19 |
| ready_table | 64 | 64 | 19 |
| free_list | 32 × 13 | 13 | 4 |
| **合计** | | **8242** | **≈2400** |

每 bit 按 0.29 µm²（DFFHQNx1）；部分结构（如 RS 数据位）可用无复位 DFFLQNx1（同价）或压缩编码，此处为上限估算。

## 3. 预算与达标策略（口径见 docs/description.md）

实测默认参数单发射全核 **7768.5 µm²**，落在第 1 档面积上限 10000 µm² 之内（余量 ≈22%）。
三档要求"面积上限与最低 IPC **同时**满足"：(10000, 0.6000) / (20000, 0.7800) / (40000, 1.0140)。
即 **默认配置下面积已不是瓶颈，IPC 才是**：第 1 档已达标，往第 2/3 档走只需 IPC 上去，无需再压面积。

第 2 节按触发器估算的存储 ≈2400 µm² 只占实测的 ~31%，其余 ~5300 µm² 是阵列的外围逻辑
（读端口多路选择、标签/年龄比较、唤醒与旁路网络）—— 故降面积的手段是**缩小阵列规模**（下表），
而不是优化触发器本身：

| 参数 | 默认 | 最小合理 | 面积影响 |
|---|---|---|---|
| ROB_SIZE | 32 | 8 | -1000 bit ≈ -290 |
| RS_SIZE | 16 | 4 | -1740 bit ≈ -507 |
| PRF_SIZE | 64 | 16 | -1536 bit ≈ -448 |
| LSQ_SIZE | 16 | 4 | -990 bit ≈ -289 |
| BHT/RAS | 32/8 | 16/4 | -130 ≈ -38 |

最小配置存储合计 ≈ (8242-5260) × 0.29 ≈ **870 µm²**；全核实测值待 §4 扫描补齐
（§2 的 2400 估算只计触发器，比实测的 7768 低得多，这个偏差本身就是"外围逻辑占大头"的证据）。
1.3× 口径（description.md 的档位设计：IPC ×1.3 ↔ 面积上限 ×2）：双发射 vs 单发射的实测面积比与 IPC 比对照。

## 4. 消融实验设计（Phase B 后执行）

- 固定点：多发射数（单/双发射）、工艺角（RVT+TT）
- 扫描：ROB_SIZE / RS_SIZE / PRF_SIZE / LSQ_SIZE / BHT_SIZE / RAS_SIZE 各 2-3 档（含默认与最小配置）
- 内存延迟必须含 **20 拍**（description.md：性能阶段的评分要求，功能仿真才是 3 拍），与 MEM_INFLIGHT 联合扫
- 每档记录：`make synth-cpu` 面积 + IPC（评测口径用 Verilator 跑 CPU-2026-Benchmark；
  本仓库内部对照先用 `tb_cpu_prog` 的 `+PERF=N` 定拍数模式，两者口径需在报告中说明）
- 输出：面积-IPC 曲线，标注每档是否满足三档约束（10000/0.6000、20000/0.7800、40000/1.0140），选面积最小且 IPC 达标的配置
- 1.3× 验证：单发射 vs 双发射，面积翻倍内 IPC 是否 ≥1.3×
